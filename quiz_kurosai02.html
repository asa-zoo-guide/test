----もし、この大きな植木屋さんが仕事をしなくなったら森はどうなるのでしょうか。サバンナはうっそうとした藪になってしまうのではないでしょうか！ それは大変! 何が大変？

【問題】 サバンナが藪になってしまうと、何が起きるでしょうか。以下の三つの内、間違っているものが一つあります。
クロサイ は、じめん の くさ を たべる シロサイ とは ちがって、おもに ひくい き の えだ や は、かじつ を たべる ので、サバンナ が き で うめつくされる のを ふせいでお います。 だから、もし クロサイ が いなく なると、ひくい き が のびほうだい に なって みとおし の わるい うっそう と した やぶ に かわって しまいます。 すると、ひろい 草原 を 好む シマウマ や ガゼル、それらを かる ライオン や チーター といった ほかの どうぶつたち が いきづらく なって しまう の です。 そして、やぶ を 好む ツェツェバエ などの こんちゅう の せいそくいき が ひろがり、ねむりびょう などの かんせんしょう の きょうい が ひろがって しまいます。
